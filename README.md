# Teams Invitation Viewer 0.1.0（試験版）
Thunderbird 160 macOS を対象とした未署名アドオン。アドオンとテーマの歯車から「ファイルからアドオンをインストール」を選択。拒否された場合は開発用の一時読み込み（デバッグ画面で manifest.json を選ぶ）を使用し、署名設定を弱めないこと。メールを開き直す。
メール表示時のみ MIME の ICS を読み取り、JST で表示する。原本・フィルター・カレンダーは変更しない。外部送信なし。参加リンクは既存本文の許可した Teams ホストの HTTPS リンクのみ使用する。
制約: 実機未検証。本文比較は 24 時間形式の時刻範囲のみで、日付・TZ・自然文は未対応。独自 VTIMEZONE、TNEF、繰り返し展開、通知間の最新判定は未対応。複数候補・解析不能時は確認を促す。会議の正しさを保証しない。
テスト: node test.js。ビルド: sh build.sh。

## v0.1.2
メインツールバー、ツールメニュー、メール一覧の右クリックを追加。MV3 の scripting API に変更。実機未検証。

## 0.1.4
ポップアップにICS基準時刻、曜日・期限、次回候補、DESCRIPTION/X-ALT-DESCの開始時刻の差分、Teamsリンクを表示。次回候補はUTC/JSTの単純な日次・週次ルールのみ。COUNT、例外、非対応ルールでは算出しない。他メールの変更通知未照合。本文自動表示は従来版のまま。実機未検証。

## 0.1.5

## 0.1.7
